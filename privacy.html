プライバシーポリシー

このポリシーは、Sheegyyが個人利用向けに運営するMyGoogleFitSample（Personal Health Sync）に適用されます。

アクセスする情報

本人のOAuth同意に基づき、Google Health API v4で読み取り可能な睡眠、心拍・心拍変動・酸素飽和度・呼吸数、歩数・カロリー・距離・階数・活動時間、運動・水泳・VO₂max、体重・体脂肪・身長・体温、血糖値、食事・水分・食品情報、心電図・不整脈通知を読み取ります。プロフィール、設定、接続端末、運動に記録されたGPS経路も対象です。各項目はデータが記録され、本人が権限を許可し、Google側がアクセスを認める場合に限り取得します。読み取り非対応の月経・排卵検査・症状・気分の型を取得したとは扱いません。

位置情報は運動データのTCX書き出しに含まれる経路であり、このアプリが端末の位置を新たに追跡する処理ではありません。心電図などの健康情報と経路情報は特に機密性が高いため、保存先を本人だけが利用する状態で運用してください。Google Healthアカウントの接続確認、対象期間と取得時刻、項目ごとの取得状態、および保存先Driveファイルの識別情報も扱います。Googleアカウントのパスワードは取得しません。

利用目的

本人の健康記録を本人指定のDriveファイルへ同期する目的にのみ利用します。健康情報の販売、広告配信、広告向けプロファイリング、信用評価への利用、汎用AIモデルの学習への利用は行いません。

保存場所・保護・保存期間

健康記録と運動経路は利用者のGoogle Driveに保存し、同期ファイルの内容は原則として直近14日分で置き換えます。プロフィール・設定・食品辞書は取得時点の状態です。高頻度の心拍や活動量は主に1時間単位の集計で、日別歩数・カロリーも併記します。記録がない場合とAPIが利用不可の場合を区別して保存します。Driveの版履歴やバックアップの保持は、Google Driveと利用者の設定に従います。

処理は利用者が管理するMicrosoft Azureで行います。OAuth認証情報はAzure Key Vaultに保管し、初回認可を行う本人のPCにも認証用ファイルが作成されます。これらの認証情報は、接続解除や運用終了時に利用者が削除します。サービス間の通信にはHTTPSを使用します。

アプリの運用ログには成功・失敗、取得件数などを記録します。アプリの処理では、生の健康記録、トークン、クライアントシークレットをログに出力しません。Azureの監視ログの保持期間は、利用者のAzure設定に従います。

共有・第三者サービス

処理に必要なGoogleとMicrosoft Azure以外へ、健康情報をアプリから自動転送することはありません。運営者が健康情報を販売することはありません。Driveファイルの自動公開や共有権限の追加は行いません。ただし、選択したフォルダーの既存の共有設定を継承する場合があるため、利用者自身で保存先のアクセス権を確認してください。

ChatGPTなどの接続アプリへDriveファイルを読ませるかどうかは、利用者による別の選択です。その場合の取り扱いには、選択したサービスのポリシーも適用されます。この説明サイト自体には、健康情報の入力欄、広告、解析タグ、独自のCookieを設置していません。サイトの配信にはGitHub Pagesを使用し、配信基盤は技術的なアクセスログを処理する場合があります。

権限の撤回・削除

Googleアカウントのサードパーティ接続から、このアプリのアクセス権を撤回できます。Azure Functionsを停止することでも同期を停止できます。権限の撤回だけでは既存データは自動削除されないため、Driveファイル、PCの認証ファイル、Key Vaultの認証情報、運用ログは必要に応じて利用者が削除してください。削除済みシークレットの保持にはAzure Key Vaultの回復可能な削除設定が適用されます。

Google APIのユーザーデータ

Google APIから受領した情報の使用は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。
